<h2><a href="https://www.geeksforgeeks.org/problems/find-distinct-elements2054/1">Common in Rows of a Matrix</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given a square<strong> </strong>matrix <strong>mat[][]</strong> of size <strong>n*n</strong>, count all the distinct elements common to all rows of the matrix.</span></p>
<p><strong><span style="font-size: 18px;">Examples :</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> mat[][] = [[2, 1, 4, 3], [1, 2, 3, 2], [3, 6, 2, 3], [5, 2, 5, 3]]
<strong>Output:</strong> 2
<strong>Explanation:</strong> Only 2 and 3 are common in all rows.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> mat[][] = [[12, 1, 14, 3, 16], [14, 2, 1, 3, 35], [14, 1, 14, 3, 11], [14, 5, 3, 2, 1], [1, 18, 3, 21, 14]]
<strong>Output:</strong> 3
<strong>Explanation:</strong> 14, 3 and 1 are common in all the rows.</span></pre>
